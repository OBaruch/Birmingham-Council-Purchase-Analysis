# EDA Outputs

The `EDA/` folder contains charts generated by [AutoViz](https://github.com/AutoViML/AutoViz) for each stage of the pipeline. They are historical outputs of the original runs and are kept unchanged.

| Folder | Dataset | Generated by |
|---|---|---|
| `EDA/data/AutoViz/` | `Data/data.csv` (raw) | Notebook run (call commented out in the `.py` script) |
| `EDA/data_clean/AutoViz/` | `Data/data_clean.csv` | Notebook run (commented out in the script) |
| `EDA/data_clean_treated/AutoViz/` | `Data/data_clean_treated.csv` | Notebook run (commented out in the script) |
| `EDA/data_clean_treated_normalized/AutoViz/` | `Data/data_clean_treated_normalized.csv` | Notebook and `EDA_and_Tranformations.py` (refreshed in the last original commit) |

Each folder contains: `Bar_Plots.png`, `Dist_Plots_Cats.png`, `Dist_Plots_Numeric.png`, `Heat_Maps.png`, `Violin_Plots_1_.png`; the raw stage also has `Pair_Scatter_Plots.png`.

## Visual findings (from reviewing the images)

### Raw data – numeric distributions (`EDA/data/AutoViz/Dist_Plots_Numeric.png`)
- `ORIGINAL GROSS AMT`, `TRANS ORIGINAL NET AMT` and `BILLING GROSS AMT` are extremely right-skewed (skew ≈ 245, 149 and −255 respectively), with a few transactions in the millions and a refund near −490,000.
- `TRANS TAX RATE` is essentially bimodal: 0 % and 20 % (standard UK VAT), with a few 5 % and 12.5 % values.

These extreme values motivate the 1 %/99 % winsorization applied in the treatment step.

### Normalized data – correlation heat map (`EDA/data_clean_treated_normalized/AutoViz/Heat_Maps.png`)
- `TRANS CAC CODE 4`–`8` are almost perfectly correlated with each other (0.86–1.0), and strongly negatively correlated with `TRANS CAC CODE 1`–`3` (≈ −0.65 to −0.84) – the CAC codes behave as a hierarchy/redundant set.
- `TRANS VAT DESC` correlates moderately with the CAC codes (|r| ≈ 0.37–0.51).
- `ORIGINAL GROSS AMT` has weak correlation with every other (label-encoded) feature (|r| ≤ 0.13).

Note that correlations between label-encoded categorical columns depend on arbitrary code ordering and should be read as indicative only.
